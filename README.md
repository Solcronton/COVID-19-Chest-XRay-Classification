# COVID-19 Chest X-Ray Classification

## About the Project
This project uses Deep Learning to classify chest X-ray images and identify patterns associated with COVID-19.

A Convolutional Neural Network (CNN) is used to learn features from chest X-ray images and perform image classification.

## Dataset
**COVID-19 X-ray Dataset (Train & Test Sets)**

The dataset contains chest X-ray images divided into training and testing sets.

## Technologies Used
- Python
- TensorFlow / Keras
- NumPy
- Pandas
- Matplotlib
- OpenCV
- Deep Learning
- Convolutional Neural Networks (CNN)

## Project Workflow
1. Load the chest X-ray dataset.
2. Perform image preprocessing.
3. Prepare training and testing datasets.
4. Build a CNN model.
5. Train the model using training images.
6. Evaluate the model using test images.
7. Predict classes for new chest X-ray images.

## Model
The project uses a Convolutional Neural Network (CNN) for image classification.

## Installation

Clone the repository:

```bash
git clone https://github.com/Solcronton/COVID-19-Chest-XRay-Classification.git
```

Navigate to the project directory:

```bash
cd COVID-19-Chest-XRay-Classification
```

Install the required libraries:

```bash
pip install -r requirements.txt
```

## How to Run

Run the main Python file:

```bash
python main.py
```

If you are using Jupyter Notebook or Google Colab, open the notebook and execute the cells sequentially.
